Terminal & CLI Quick Reference

Comandos esenciales de administración para la flota de servicios en macOS Hackintosh. Haz clic en "COPIAR" para pegarlos directamente en tu terminal.

1. Supervisor PM2 (Estado, logs y reinicio)
pm2 status # Ver todos los 36 procesos
pm2 save # Guardar estado actual para arranque
pm2 restart all # Reiniciar toda la flota
2. Verificación de Puertos en Vivo (0 Colisiones)
lsof -iTCP -sTCP:LISTEN -P -n | grep -E 'node|python|cloudflared|ollama'
3. Tailscale VPN (Red Mesh 100.100.2.10)
tailscale status # Ver dispositivos conectados (Redmi, iPhone, VPS)
tailscale ip -4 # Debe devolver: 100.100.2.10
4. Solución PostgreSQL para cuentos-magicos-backend
# Opción 1: Levantar Postgres.app o brew services
brew services start postgresql@14
pm2 restart cuentos-magicos-backend
