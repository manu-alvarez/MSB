🚀 Guía para 100% Producción

¿Cómo desplegar este agente en un entorno real?

Este frontend genera la especificación (spec.json) y los artefactos base. Para ejecutar el agente de verdad y que no sea solo un prompt, necesitas un Backend de Ejecución (AURORA, LangChain o LlamaIndex).

1. Variables de Entorno (APIs)

No usamos APIs directamente en este frontend para proteger tus claves. En tu servidor (Node.js/Python), debes configurar:

OPENAI_API_KEY=sk-...
GEMINI_API_KEY=AIza...

2. Ingesta del spec.json

El backend debe leer el archivo spec.json exportado. Ejemplo en Node.js:

const spec = JSON.parse(fs.readFileSync('agente-spec.json'));
const agent = new AuroraEngine({
  systemPrompt: spec.outputs.systemPrompt,
  tools: parseManifest(spec.outputs.toolManifest),
  model: 'gemini-2.5-pro'
});

3. Implementación de Herramientas (Tool Manifesto)

Si activaste los pilares de RAG o Herramientas, el motor exportará un Tool Manifesto. Debes implementar el código real de esas herramientas en tu backend (ej. conexión a una base de datos vectorial para RAG).

4. Frontend de Usuario Final

Este UI (Agent Forge) es para construir el agente. El usuario final necesitará una interfaz de chat conectada a tu backend vía WebSockets o API REST.
